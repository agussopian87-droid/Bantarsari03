# Pilkades Bantarsari — Prototype Demo

Prototype sederhana tanpa database. Cocok untuk belajar dan simulasi di HP/komputer.

## Fitur
- Verifikasi DPT demo
- Pilihan 3 calon
- Pencegahan pemilih demo memilih dua kali
- Dashboard panitia
- Rekap suara
- Rekap TPS
- Data tersimpan di localStorage browser

## Data demo
- TPS 1: D1-1 s.d. D1-5
- TPS 2: D2-1 s.d. D2-5
- TPS 3: D3-1 s.d. D3-5
- Calon nomor 3: Agus Sopian, S.T.

## Menjalankan
Buka `index.html` langsung di browser.

## GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, `app.js`, dan `README.md`.
3. Masuk Settings → Pages.
4. Pilih Deploy from a branch.
5. Pilih branch `main` dan folder `/root`.
6. Simpan. GitHub akan memberikan alamat Pages.

## Catatan penting
Ini hanya prototype/simulasi. Jangan gunakan untuk pemungutan suara Pilkades resmi. Untuk sistem nyata diperlukan backend/database, autentikasi kuat, audit, keamanan, pemisahan identitas pemilih dari pilihan suara, backup, dan kepatuhan terhadap aturan Pilkades yang berlaku.
